hahacium 隐私权政策

生效及最近更新日期：2026 年 10 月 13 日

1. 适用范围与运营主体

本政策适用于 hahacium 品牌宣传官网（以下简称「本网站」），由 hahacium 网站运营者（以下简称「我们」）负责维护。本网站用于展示品牌信息并提供联系渠道，不提供账号注册、登录、在线交易或用户内容上传功能。

本政策说明浏览本网站或通过电子邮件联系我们时，相关信息的处理方式。隐私联系邮箱为 lxin9075@gmail.com。

2. 浏览网站与技术信息

本网站是静态展示网站，页面不包含信息收集表单、访问统计脚本、广告追踪工具或第三方嵌入内容，也不通过页面代码设置 Cookie 或使用浏览器本地存储来识别访客。仅浏览页面无需向我们提供姓名、邮箱或其他身份资料。

本网站通过 GitHub Pages 托管。为提供网页访问及维护服务安全，GitHub 会记录访问者的 IP 地址，并可能处理请求时间、浏览器信息等技术数据。这些托管平台数据的处理和保留由 GitHub 按其 隐私声明管理；我们不另行建立访客追踪数据库。

3. 主动联系时提供的信息

当你向我们的联系邮箱发送邮件时，我们会收到你的发件地址、邮件正文、附件，以及你主动提供的姓名或其他信息。这些信息仅用于：

  • 回复咨询、品牌联系或反馈。
  • 处理隐私请求、网站问题和必要的后续沟通。
  • 在确有必要时履行法律义务或处理争议。

我们不会将这些信息用于未经你同意的营销邮件。请勿通过邮件发送账号密码、支付资料或与咨询无关的敏感信息。

4. Google 账号与 API 数据

本网站不提供 Google 登录，不发起 OAuth 授权请求，不申请 Google API 权限，也不通过 Google API 读取、保存或共享你的账号资料、邮件、云端文件或其他 Google 用户数据。

你主动发送到联系邮箱的邮件仅按本政策第 3 节处理，不属于通过 Google API 授权访问你的账号。如未来增加登录或数据访问功能，我们会在启用前更新本政策，说明具体数据、用途、保存方式及用户选择，并在需要时取得授权。

5. 数据共享与第三方服务

我们不出售或出租你提供的个人信息，不向广告商或数据经纪商提供这些信息。除提供网站托管和邮件通信所需的服务、取得你的同意或依法必须披露外，我们不向其他第三方披露你的联系信息。

本网站使用 GitHub Pages 提供网页托管，并使用 Gmail 接收和回复邮件。邮件会由 Google 的邮件服务处理，相关处理方式见 Google 隐私权政策。这些服务提供商可能在你所在国家或地区以外处理数据。

点击外部链接后，第三方网站将按其自身政策处理信息。本政策仅适用于本网站及我们处理的联系信息。

6. 存储、安全与保留期限

本网站不建立用户账号或存储访客个人资料的业务数据库。你主动发送的联系信息主要保存在联系邮箱中，仅限处理相关事务的人员使用。我们采取合理措施保护联系信息，但任何互联网传输或存储方式都无法保证绝对安全。

联系邮件仅在回复咨询、完成后续沟通、处理争议或满足适用法律要求所必需的期间保留。相关目的完成且无继续保留的必要时，我们会删除有关邮件，或应你的有效请求删除。依法需要继续保留的，仅保留必要范围的信息。

GitHub 和 Google 对其平台日志、备份及相关数据的保留和清除依各自政策执行，我们无法直接控制其基础设施中的清除时间。

7. 你的选择与隐私请求

你可以在不发送邮件或提供个人资料的情况下浏览本网站。对于你主动提供给我们的个人信息，你可发送邮件至 lxin9075@gmail.com，申请了解处理情况、访问、更正或删除信息，或在适用时撤回同意、限制或反对处理。

我们会在适用法律规定的期限内处理有效请求，并在必要时进行与请求风险相适应的身份核实。如部分信息因法律义务或争议处理需要无法删除，我们会说明原因。由托管或邮件平台独立控制的数据，可按其隐私政策向相应平台提出请求。

本网站不取得 Google 账号访问授权，因此没有需要通过本网站撤销的 Google OAuth 权限。

8. 政策更新

我们可能根据网站功能或适用要求更新本政策，并在本页面标明最近更新日期。如果新增数据收集功能或显著改变信息用途，我们会在相关功能启用前作出清晰说明，并在法律要求时取得同意。
